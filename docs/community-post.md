# Introducing F1 Pit Wall Insights — Local Analytics → Sisense

Hey everyone 👋

I just shipped something I'm excited about.

It's a working analytics dashboard that shows the journey from prototyping locally to scaling with Sisense.

**Why this matters:**

Most BI platforms want you to start inside their tool. But developers start in their IDE, building locally, validating ideas. There's always a gap.

This repo proves you can:
1. Prototype analytics in React (locally, zero friction)
2. Validate the UX before any platform commitment
3. Upgrade to Sisense Compose SDK when you need scale
4. Never rebuild your product experience

**The demo:**
- Clone it
- `npm run dev`
- See analytics working in 2 minutes
- No signup. No setup. No BS.

Then fork it, customize it, deploy it.
