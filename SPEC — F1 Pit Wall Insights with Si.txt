SPEC — F1 Pit Wall Insights with Sisense
1. מטרת הפרויקט

לבנות prototype קצר שמדגים איך builder יכול לקחת דאטה פתוח של Formula 1, לעבד אותו במהירות בעזרת Python, ולהפוך אותו ל־embedded analytics experience בתוך אפליקציה — בעזרת Sisense.

הפרויקט צריך להוכיח שלושה דברים:

Hands-on build — יש קוד, דאטה, אפליקציה, גרפים ותובנות.
Strategic thinking — יש קהל ברור: builders / vibe coders / sports-data hackers.
Technical storytelling — יש סיפור פשוט:
Vibe coding can create a dashboard. Sisense turns it into an embedded insight experience.

המשימה של Sisense בנויה בדיוק על שלושת הצירים האלה: Strategy, Build, Story, עם משקל של 30% / 40% / 30%, והם מדגישים שדמו פשוט עם narrative חד עדיף על פרויקט מורכב מדי.

F1 Pit Wall Insights

3. הקהל
Primary Audience

AI-native builders, vibe coders, technical founders, product engineers, and developer advocates who build apps quickly with tools like Cursor / Claude Code / Lovable / Replit — and want to add serious analytics without building a BI layer from scratch.

Secondary Audience

Sports-data fans / F1 technical communities who understand the value of telemetry, lap-time deltas, tyre degradation, and race strategy.

5. מקור הנתונים

מקור הנתונים יהיה FastF1.

FastF1 היא ספריית Python שמאפשרת גישה וניתוח של נתוני Formula 1 כמו timing data, telemetry, session results ועוד. היא מחזירה דאטה במבנים שמתאימים לעיבוד ב־Python / Pandas.

גם בפרויקט F1 Race Replay מהסרטון, היוצר אומר שהמקור היחיד של הפרויקט הוא FastF1, והוא משתמש בה ל־driver info, session results ו־telemetry.

לא לבנות מערכת גדולה.

8. ארכיטקטורה
FastF1 API / Python package
        ↓
Python ETL script
        ↓
CSV files / optional PostgreSQL
        ↓
Sisense Trial data model OR local explicit data fallback
        ↓
React / Next.js app
        ↓
Sisense Compose SDK charts
        ↓
Insight panel + Builder README + content asset

Sisense Compose SDK מאפשר לבנות analytics ו־data-driven experiences מתוך קוד, כולל queries, charts ו־filters, ללא תלות בדשבורדים מוכנים מראש. הוא תומך ב־React / Angular / Vue / TypeScript ומיועד לבנייה code-first של analytics בתוך מוצר.

Compose SDK Charts יכולים לעבוד מול data source מתוך Sisense instance, וגם מול explicit data שמגיע מבחוץ במבנה טבלאי מתאים. זה חשוב כ־fallback אם סביבת ה־trial תעשה בעיות.

11. Insight Logic

לא צריך ML.
צריך rules פשוטים שמייצרים תובנות הגיוניות.

File
/etl/transform_insights.py
Insight 1 — Pace Advantage

Logic:

חשב average lap time לכל נהג בטווח ההקפות.
מצא מי מהיר יותר.
חשב gap ממוצע.

Output:

{
  "title": "Pace Advantage",
  "insight": "VER was on average 0.42s faster per lap than PER across the selected stint.",
  "why_it_matters": "A consistent pace gap over multiple laps usually matters more than a single fastest lap."
}
Insight 2 — Tyre Degradation

Logic:

לכל stint, חשב rolling average של lap time.
השווה תחילת stint לסוף stint.
אם lap time עולה ביותר מ־X שניות — סמן degradation.

Output:

{
  "title": "Tyre Degradation Signal",
  "insight": "Lap times started increasing after lap 17, suggesting the tyre performance window was closing.",
  "why_it_matters": "This can indicate the optimal pit window before pace drops too much."
}
Insight 3 — Strategy Moment

Logic:

מצא lap שבו delta השתנה הכי הרבה.
סמן אותו כ־race turning point.

Output:

{
  "title": "Strategy Moment",
  "insight": "The largest delta shift happened around lap 21, which may indicate traffic, tyre drop-off, or pit strategy impact.",
  "why_it_matters": "This is where a race engineer would look first."
}
Insight 4 — Builder Note

Output קבוע:

{
  "title": "Builder Note",
  "insight": "The key lesson is not the chart itself. It is how raw telemetry becomes an embedded decision experience.",
  "why_it_matters": "This is the role Sisense can play for AI-native builders."
}

14. README Structure
README.md
# F1 Pit Wall Insights with Sisense

Vibe coding makes it easy to generate dashboards.
But serious analytics needs structure, trust, and context.

This prototype shows how a builder can take raw Formula 1 telemetry, process it with Python, and turn it into an embedded analytics experience using Sisense.

## Why this matters

F1 fans don't need more charts.
They need to understand where the race was won or lost.

For builders, this demo shows a broader point:
Sisense can become the analytics layer inside AI-built products.

## What it does

- Extracts F1 timing and telemetry data using FastF1
- Transforms lap, stint, tyre, and delta data into analytics-ready tables
- Displays embedded analytics charts in a React app
- Generates plain-English pit wall insights
- Includes prompts for AI-native builders to recreate or extend the experience

## The builder story

Vibe-code the product experience.
Use Sisense as the analytics foundation.

## How to run

### 1. Extract data

```bash
cd etl
pip install -r requirements.txt
python extract_fastf1_data.py
python transform_insights.py
2. Run the app
cd app
npm install
npm run dev
3. Optional Sisense Trial path

Upload the processed CSV files into Sisense Trial and connect the Compose SDK components to your Sisense data model.
