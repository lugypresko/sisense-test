The Bet: A senior full-stack engineer at a B2B SaaS company needs embedded analytics in weeks, not quarters. Traditional BI platforms require a 6-month sales cycle and a dedicated BI team. Part 3: The Call to Action (PLG Funnel)

The Developer Journey: Awareness → Activation → Conversion

The fundamental challenge:

A developer on the sidelines is either skeptical or busy (usually both). The only thing that moves them is a working artifact they can immediately touch.

Step 1: Awareness (Make the Prototype the Pitch)

CTA (Top of Funnel):

"Fork this repo. Add embedded analytics to your React app in under 10 minutes."

NOT: "Sign up for Sisense" or "Learn Compose SDK"

Why This Works:

  • Developer immediately sees the problem solved (embedded charts in React)
  • No signup wall between discovery and trying
  • The repo itself is the sales pitch

Execution:

  • GitHub README (clear, no jargon)
  • Live demo link (one click)
  • Social proof: "200 developers forked this" (once it gains traction)

Step 2: Aha Moment (<5 minutes, Zero Friction)

What Must Happen: Developer reaches: "This actually works in my stack."

How:

  1. StackBlitz / CodeSandbox Embed (in README)

    • Developer sees live chart rendering in browser
    • No account required
    • Click → see working dashboard

  2. Local Run is Instant

   git clone <repo>
   npm install && npm run dev
   # 2 minutes later: dashboard is live

  1. No Sisense Config Needed Yet

    • Local mode works with zero setup
    • Sisense is optional (but shown as upgrade path)

Success Metric: "I could ship this in my product" thought

Step 3: Activation (npm install = Real Signup)

The Key CTA:

npm install @sisense/sdk-ui

Why This Matters:

  • This is the real activation moment
  • Developer has self-selected as active evaluator
  • Track this: npm install events (not form fills)

Follow-Up Path:

  1. "Now add real data"
   VITE_SISENSE_URL=your-instance
   VITE_SISENSE_TOKEN=your-token
   # Restart
   npm run dev
  1. Same UI, real Sisense backend
  2. Multi-tenancy works out-of-the-box
  3. Deploy to production when ready

Conversion Metric: Trial signup + Compose SDK installation

Step 4: Habit Loop (Community)

How to Keep Them Engaged:

  • GitHub Discussions on Compose SDK repo (technical Q&A)
  • "Built with Compose SDK" showcase (let devs self-submit)
  • Weekly changelog with code examples (developers subscribe to repos, not newsletters)

What NOT to Do:

  • Don't send marketing emails
  • Don't require webinars
  • Don't "nurture" them in a CRM

What TO Do:

  • Answer technical questions (fast)
  • Share community builds
  • Show off advanced features through real code examples

Step 5: Conversion (Value Does the Selling)

When They're Ready to Pay:

Developer hits a limit that requires Sisense:

  • Multi-tenancy at scale (>10 customers)
  • White-labeling / white-glove customization
  • SSO + advanced security
  • AI Assistant features (natural language queries)
  • Advanced data governance

The Story They Tell Their Team:

"I built embedded analytics for our product using Sisense."

Sisense is the hero? NO.

"I was the hero. Sisense was the tool."

This matters: A developer who tells that story internally is Sisense's most effective sales rep. They cost zero dollars.
