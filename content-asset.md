# I Built an F1 Pit Wall with Sisense Thinking

Vibe coding can generate a dashboard fast.

But Formula 1 data exposes the real problem: a chart can show lap times, but it does not explain where the race was won or lost.

So I built a small Python-first prototype: F1 Pit Wall Insights.

It takes processed F1 lap data and turns it into a local analytics experience with:

- lap time trends
- driver delta
- tyre degradation signals
- strategy moments
- plain-English pit wall insights

The goal was not to build another F1 dashboard.

The goal was to show how AI-native builders can move from generated visualizations to trusted analytics experiences.

That is where Sisense becomes interesting.

Vibe-code the product experience. Use Sisense as the analytics foundation.
