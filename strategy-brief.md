# Strategy Brief - F1 Pit Wall Insights

## Audience

AI-native builders, vibe coders, product engineers, and technical founders who build apps quickly and want analytics that feels trusted, reusable, and embedded.

## Pain Point

Generated dashboards are easy. Analytics gets harder when teams need consistent data models, clear filters, explainable metrics, and reusable insight experiences.

Formula 1 is a strong demo domain because lap time, tyre life, and driver delta create a simple question: where was time gained or lost?

## Prototype

F1 Pit Wall Insights loads processed Bahrain GP 2024 lap data, renders a local Streamlit analytics surface, and explains the strategy signals in plain English.

## Why Sisense

Sisense can become the analytics layer for builders who do not want to rebuild BI foundations from scratch. This local demo keeps the integration optional but prepares the architecture for a Compose SDK path.

## Distribution

- Formula 1 technical communities
- Sports-data communities
- Cursor and Claude Code builder communities
- Dev.to
- LinkedIn technical builders
- Product engineering communities

## CTA

Run the local demo. Inspect the adapter boundary. Connect Sisense when an instance and API token are available.
